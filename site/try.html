The paid gate is plain x402 over HTTP; any x402 client pays it. Free verdicts take either a wallet signature (fetch GET https://mcp.djzs.ai/try/quota for the text, sign it, post it) or an anonymous 32-hex id with a smaller cap.

POST https://mcp.djzs.ai/x402/verify_pm_trade      # or /x402/verify_perp_trade
{ "intent": { "thesis": "free text, or the structured fields: market, side, probability_basis, size_usd, bounds" } }
# 402 -> pay 2.00 USDC (exact, eip155:8453) -> 200 verdict + eas_uid + PAYMENT-RESPONSE

{ "kind": "pm", "intent": { ... }, "anon": "32 lowercase hex" }                       # 3 per id per UTC day
{ "kind": "pm", "intent": { ... }, "address": "0x...", "day": "YYYY-MM-DD", "signature": "0x..." }   # 5 per wallet

MCP clients: claude mcp add --transport http djzs-trust https://mcp.djzs.ai/mcp, then verify_pm_trade or verify_perp_trade. Full guide at /guide; the ruleset and every weight at /ruleset.

free verdict: same engine, same ruleset, not attested, not anchored. Extraction contract stated in every response.
receipt: EAS on Base, attester 0xfB0e…7824, your wallet as recipient. Under schema v3 the verdict is re-derived on chain from the attested tally.
audit, not advice: a reasoning verdict says whether the idea is complete and free of the listed defects. It does not check that your facts are true, and never says the trade wins. The example is a real market and a real thesis; it is not a recommendation. Terms.
