for agents · no browser

    
The paid gate is plain x402 over HTTP; any x402 client pays it. Free verdicts need the same wallet signature this page makes: fetch GET https://mcp.djzs.ai/try/quota for the text, sign it, post it.


POST https://mcp.djzs.ai/x402/verify_pm_trade      # or /x402/verify_perp_trade
{ "intent": { "market": "...", "side": "YES", "thesis": "...", "probability_basis": "...",
              "size_usd": 250, "bounds": { "max_loss_usd": 250, "exit_condition": "..." } } }
# 402 -> pay 2.00 USDC (exact, eip155:8453) -> 200 verdict + eas_uid + PAYMENT-RESPONSE

POST https://mcp.djzs.ai/try/verdict                 # free, 5 per wallet per UTC day
{ "kind": "pm", "intent": { ... }, "address": "0x...", "day": "YYYY-MM-DD", "signature": "0x..." }

    
MCP clients: claude mcp add --transport http djzs-trust https://mcp.djzs.ai/mcp, then verify_pm_trade or verify_perp_trade. Full guide at /guide; the ruleset and every weight at /ruleset.
